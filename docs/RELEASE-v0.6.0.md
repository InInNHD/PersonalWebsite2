# v0.6.0 — 文章归档、个人介绍与暗色响应式布局

本地开发阶段的预发布版本，基于 v0.5.0 增加文章归档、关于页、首页个人简介和全站暗色响应式布局。Release 提供源码，运行环境与数据库由使用者自行准备。

2026-10-15：本轮经用户授权提交并发布为 v0.6.0 预发布版本。发布基线为 v0.5.0（2d7be4d），版本标签绑定包含本轮业务、测试和文档的发布提交。

## 本次更新

- 新增 `/archive` 归档页面和顶部导航入口。
- 月份目录按年月倒序，选择框按年份分组，默认选最新有公开文章的月份。
- 月内复用现有文章分页，每页 10 篇，按首次发布时间及编号降序排列。
- 选择月份回到第一页，文章标题可进入原详情页。
- 草稿不进入目录、月内列表及文章总数，只有草稿的月份不显示。
- 支持加载错误提示和重新加载，过期请求不覆盖当前月份、列表或错误状态。
- 补齐归档回归测试，检查闰年月份边界、跨年计数、非法参数、分页、空目录、重试及卸载。
- 新增 `/about` 关于页及首页个人简介，网站名、昵称、介绍与 GitHub 入口集中在 `frontend/src/siteProfile.js`。
- 顶部导航增加关于入口，首页、关于页与页脚共享介绍文案。
- 全站采用暗色技术风格，统一正文、卡片、链接、错误提示、表单、按钮和焦点样式。
- 完善手机与平板布局：窄屏筛选单列、导航换行、后台写作区域按窗口宽度调整。
- Markdown 代码和宽表格在各自区域横向滚动，图片随容器缩放，长标题、标签和链接可换行。
- 补充第七至第九轮手敲指南、关于页验收及暗色移动端验收记录。

## 接口与兼容性

新增公开接口 `GET /api/articles/archive`，返回数组，每项为 `month`（YYYY-MM）和 `total`（该月公开文章数量）。没有公开文章时返回空数组。

现有列表 `GET /api/articles` 新增可选 `month` 参数，接受 1000～9999 年的合法月份。月份可与栏目、分类、标签、关键词同时使用，总数与本页文章复用相同条件。空值、不足两位的月份及非法月份返回 400。

列表仍返回 v0.5.0 的分页对象；未传月份时原首页行为不变。详情与管理员接口的格式不变，没有新增数据库表或迁移。

## 安装与升级

- 新安装仍按 README 执行 `database/000-init-article.sql` 至 `004-article-tag.sql`，配置 Java 17、Node.js、MySQL 和管理员密码。
- 从 v0.5.0 升级无需数据库迁移，更新前后端并重启即可；不要重复执行已有脚本。
- 从更早版本升级注意 v0.5.0 的列表分页对象格式，并按 README 补齐尚未应用的迁移。
- 个人介绍通过 `frontend/src/siteProfile.js` 修改；上线前替换成自己的公开文案及链接。
- 本轮提交包含归档、关于页、暗色样式、前后端测试、指南和验收文档；版本标签绑定最终发布提交。

## 当前范围

归档按现有首次发布时间分月，不使用最后编辑时间，不提供独立全年文章模式。年月格式化筛选适用于当前个人网站规模；文章量增大并且查询变慢时再评估日期范围查询和索引。

备份恢复演练、本地整体验收和云部署属于后续阶段。本版本的移动端检查使用 Chromium 浏览器视口模拟，尚未覆盖真实手机系统、Safari 和 Firefox。
