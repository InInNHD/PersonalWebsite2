# v3.0.0-alpha.1 — 首页、文章库与内容组织

日期：2026-10-24。基于v2.0.0-rc.1（02aadf4），这是第三版第一项Alpha阶段预发布，不是第三版RC、正式版或云部署。前端、锁文件与Maven构建版本统一为3.0.0-alpha.1。

## 已实现

- 新首页与 `/articles` 文章库分离；旧首页的筛选参数和支持的锚点通过replace迁移，详情地址及合法返回来源继续兼容。
- 首页精选、学习专题、专题页及专题内上一节/下一节。每次查询重新检查公开状态，不足两篇公开文章的专题隐藏并返回404。
- 独立 `/projects` 页面，展示本站案例、关联实践笔记、全部公开项目与既有三类更新快照。
- 文章库支持卡片/紧凑列表切换，在当前页面会话中从正文返回时保留布局密度。
- 配置校验、旧响应失效、加载/空/错误重试及手机导航等响应式交互。
- 保留第三版独立交互样稿与内容策划，样稿文章明确标注为演示内容，未复制私人草稿全文。

## 编排与升级

后端资源 `personalwebsite/src/main/resources/presentation.json` 配置精选、专题和项目笔记关联。**默认三项都为空**，不会将测试文章或未公开草稿自动选为精选；填写及重启步骤见[配置指南](32-v3-content-organization.md)。

本轮无SQL迁移和新增应用依赖。个人库已完成007，不要重复执行SQL；更新并重新构建、重启前后端即可。新安装仍按README执行000～007并设置数据库连接、管理员密码和媒体目录。

新增公开编排与专题读取由PresentationController提供，既有文章查询、公开隔离及管理流程继续保留。专题顺序与全站时间顺序是不同入口，专题内连续阅读保留专题来源。

## 已知限制与下一轮

实体手机触摸/软键盘仍按用户要求暂缓，浏览器宽度模拟不等于真机验收。第三版第一轮样稿中的后续阅读/写作设想不代表本轮已经实现。

本轮保留已有7个公开项目、172条记录快照，没有扩大GitHub同步范围；本次Release将在下一次成功手动同步后纳入。未公开文章仍保留草稿状态。

下一轮为服务端正文搜索、匹配片段及安全高亮、阅读字号和专注模式；后台编排与可靠写作留到第四轮。第三版正式版及RC需要后续轮次和整站验收，云部署继续后置。
