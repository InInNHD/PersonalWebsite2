# 第三版第三轮：正文搜索与阅读体验

## 使用方式

1. 在文章库打开搜索，输入标题、摘要或正文中的词，提交后从第一页显示结果。
2. 结果卡片标明“标题命中 / 摘要命中 / 正文命中”，浅绿色部分是实际匹配文字。原栏目、分类、标签和分页仍可组合使用。
3. 打开正文后可选“标准字号”（16px）或“大字号”（19px）。字号保存在当前浏览器，禁用存储时仍可使用本次选择。
4. 点击“专注阅读”收起站点页头、页脚和右侧目录，保留折叠目录、正文返回和退出按钮；按Escape退出。图片弹窗打开时，Escape先处理弹窗。
5. “复制文章链接”只复制本站 `/articles/{id}`，移除 `from`、搜索条件及章节锚点。剪贴板不可用时显示可手动复制的链接。

## 搜索规则

- 整个输入按一个普通子串搜索，不拆词、不接受正则或布尔语法。`C++`、`value_%!`、中文短词和Emoji可以作为关键词。
- 复用MySQL `LOCATE`；大小写与重音等匹配行为遵循目标字段的排序规则。本机隔离库使用 `utf8mb4_unicode_ci`。
- 搜索范围包含原始Markdown正文，因此代码、链接地址和Markdown标记也可能命中；片段不渲染为Markdown或HTML。
- 标题命中优先，其次摘要、正文；同级按发布时间降序、编号降序稳定分页。无关键词时保持原置顶排序；有月份且无关键词时保持时间排序。
- 输入去除首尾空白后最多100个Java字符，页大小1～50，页码1～1,000,000，沿用现有接口边界。
- 每篇结果只展示优先字段的第一个命中，命中前后各最多60个Unicode字符；省略部分用省略号标记。列表响应不包含完整正文。
- 公开条件始终为已发布且未回收；计数、分页、匹配片段均遵循该条件。撤回后下次请求不再返回文章或片段。

片段先由数据库按同一排序规则定位，再由Vue文本插值显示。`<script>`、`<img onerror>`等输入只能成为文字，不会转为可执行HTML。

## 接口与实现位置

`GET /api/articles?keyword=关键词&page=1&size=10` 保留原分页字段，并新增：

```json
{
  "matches": {
    "101": {
      "field": "body",
      "before": "此前的文字",
      "match": "关键词",
      "after": "后续的文字",
      "leading": false,
      "trailing": true
    }
  }
}
```

编号仅对应当前页文章；无关键词或无结果时为 `{}`。

| 文件 | 职责 |
| --- | --- |
| `ArticleController.java` | 扩展正文过滤及稳定排序，保持公开条件与分页 |
| `ArticleSearch.java` | 对当前页批量生成有长度限制的片段；兼容MySQL5.7派生表查询 |
| `SearchSnippet.vue` | 通过文本节点和mark元素显示匹配片段 |
| `ReadingTools.vue` | 字号记忆、专注开关、Escape和干净链接复制 |
| `ArticleDetailView.vue` | 切换布局时保持当前段落位置，重新计算阅读进度 |
| `readingNavigation.js` | 目录定位预留吸顶工具条的实际高度 |

## 更新与限制

无需SQL迁移，无新增依赖、表、索引或后台配置。更新两端并重启后端，前端重新启动开发服务或重新构建静态文件即可。个人内容和发布状态不会被修改。

子串检索会扫描公开候选文章，不声称适合大规模全文搜索。当前采用有界返回并测量本机表现；文章量明显增大、实测响应变慢时再评估全文索引。浏览器请求15秒超时不等同于数据库语句执行上限。

专注模式只改变布局，没有新增内容权限或自动保存；阅读字号的浏览器偏好不属于网站内容备份。分享复制的是当前访问源的地址，本机地址不能被外网访问；服务端分享元信息和RSS仍在第五轮。实体手机验收仍单独保留。
