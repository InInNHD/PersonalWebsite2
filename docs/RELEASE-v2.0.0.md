## 第二版完整更新

- 暗色技术风格、原创SVG主视觉、响应式首页、置顶/封面/摘要卡片及真实公开统计。
- Markdown阅读、代码高亮与复制、文章目录、章节锚点、阅读进度、图片大图、前后篇与来源列表位置恢复。
- 分类/多标签、组合筛选、标题摘要搜索、分页、年月归档、公开精选日记、个人介绍与GitHub项目更新链。
- 独立管理员登录与工作台、Markdown编辑/预览/分屏、草稿/发布/撤回/回收/恢复、未保存离开保护与失败保留输入。
- 资源分组、搜索、排序、推荐理由；本地PNG/JPEG校验与重编码，封面/正文显式关联及媒体公开隔离。
- 统一加载/空/错误/404、动态标题与基础描述、键盘入口及Escape焦点返回。
- 数据库、配置、源码及媒体离线备份恢复；恢复失败回滚本次创建的对象，保护已有库。
