## 1. 准备访问

手机和电脑连接同一可信Wi-Fi，电脑先按README启动后端。手机地址中的localhost指手机自身，不能直接使用电脑终端的localhost链接。

在电脑PowerShell运行 `ipconfig`，找到当前Wi-Fi网卡的IPv4地址，例如192.168.1.20。然后在项目根目录启动前端，**把下面地址换成电脑实际IPv4**：

```powershell
npm.cmd --prefix frontend run dev -- --host 192.168.1.20 --port 5173 --strictPort
```

这会将开发前端绑定到指定网卡供同Wi-Fi设备访问。端口被占用时先关闭自己的旧前端或选择另一端口，不要终止不明进程。手机访问 `http://192.168.1.20:5173`。API仍由Vite代理到电脑的后端8080，不需要在手机配置后端地址。

若无法访问，核对网卡地址、终端错误和Wi-Fi设备隔离；如系统要求放行，只针对这次开发服务与可信专用网络处理，不关闭整个防火墙，也不配置路由器公网端口转发。验收后在前端终端Ctrl+C停止局域网服务。
