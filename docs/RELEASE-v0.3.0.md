# v0.3.0：标签管理与完整数据库初始化

验证日期：2026-10-08。本版本基于 v0.2.0，作为本地开发阶段的预发布版本。

## 本次更新

- 新增标签创建、重命名、重名及输入校验。
- 支持文章多标签保存、读取、展示和清空；无效标签导致文章更新事务回滚。
- 增加标签表及文章标签关联表，列表批量查询标签。
- 补齐 `database/000-init-article.sql`，支持从空数据库创建初始文章表。
- README 补充新安装与已有数据库升级顺序、启动配置和测试命令。
- 保留前后端回归测试、手敲指南及项目进度；本地验收截图不进入源码包。

标签筛选、搜索、分页和归档仍待开发。`docs/05-tag-filter.md` 是下一轮手敲指南，不能作为本版本已实现功能。

## 新安装与升级

新安装按 `000 → 001 → 002 → 003 → 004` 执行数据库脚本，再按 README 配置四个环境变量并启动。

从 v0.2.0 升级只执行尚未应用的 `003-tag.sql`、`004-article-tag.sql`。已有标签表和关联表时跳过；迁移脚本不能重复执行。升级前备份数据库。
