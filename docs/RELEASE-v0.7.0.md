# v0.7.0 — 第二版首页、文章展示与列表导航

本地开发阶段的预发布版本，基于 v0.6.0（5c24d4c）。本轮包含第二版第二轮 A、B1、B2，整个第二版仍继续迭代，尚未部署到云服务器。

## 本次更新

- 更新全站访客框架与真实首页，增加首屏、图文卡片、作者信息、导航、页脚和响应式布局；管理页面使用独立外框。
- 增加文章封面、置顶和更新时间。封面为空或加载失败时使用栏目默认图，置顶在数据库分页前排序；归档继续按首次发布时间排序。
- 后台可保存和重新读取封面与置顶状态，封面仅允许不含账号密码的完整 HTTP/HTTPS 地址。
- 新增公开统计接口 `/api/site-stats`，只统计公开文章、关联的分类和标签，以及公开资源，不泄露草稿或隐藏资源数量。
- 列表的栏目、分类、标签、关键词和页码写入网址，支持直达、刷新及浏览器前进后退。
- 搜索和筛选回到第一页，翻页保留已提交条件，未提交的输入文字不影响翻页。
- 正文返回链接保留列表条件，并在列表异步渲染后恢复本次页面会话中的浏览位置。
- 清理非法、重复和未知参数，拒绝站外返回地址；超出末页时同步纠正网址，错误后可保留条件重试。
- 补充默认 SVG 图片、设计样稿、分轮手敲指南、回归测试，以及备份恢复和本地验收记录。

## 数据库升级与接口

**从 v0.6.0 升级必须先备份数据库，并应用尚未执行的 `database/005-article-presentation.sql`。** 本轮后端依赖新增字段，不能只更新代码而跳过迁移。

1. 先完成备份，连接 MySQL 并确认当前选中正确数据库。
2. 新安装按 README 执行 000～005；已有 v0.6.0 数据库只执行 005 一次。
3. 如果已有 `cover_url`、`pinned`、`updated_at` 三列，跳过 005，禁止重复执行 ALTER TABLE。当前开发者个人库已完成该迁移。
4. 同步更新前后端并重启，核对文章列表、统计及后台保存。

005 新增 `cover_url VARCHAR(2048)`、`pinned BOOLEAN NOT NULL DEFAULT FALSE`、`updated_at DATETIME(6)`。旧文章封面和更新时间保留 NULL，置顶默认为 false，不伪造历史修改时间。

公开列表与详情增加 `coverUrl`、`pinned`、`updatedAt`，列表保留 v0.5.0 起的分页对象。新增 `/api/site-stats` 返回 `articles`、`categories`、`tags`、`resources`。管理员文章接口增加相应展示字段；封面由访客浏览器请求，后端不下载远程图片。

## 运行与当前边界

运行需要 Java 17、Node.js、MySQL，以及 DB_URL、DB_USERNAME、DB_PASSWORD、ADMIN_PASSWORD 四项配置，详见 README。GitHub Release 提供按版本标签生成的源码下载，不包含个人数据库和私密配置。

精确列表位置只保存在当前页面会话最近 20 组查询中。整页刷新或新标签页保留网址条件，但不保证原滚动位置。当前仅支持外部封面地址，没有图片上传服务。

设计样稿中的阅读目录、代码高亮/复制、图片查看、阅读进度和独立写作后台等，不代表本轮业务代码已经实现。下一轮进入文章阅读体验，云部署仍安排在第二版产品验收之后。
