## 打开方式

在项目根目录的终端执行：

```powershell
node docs/design-v2/preview.mjs
```

打开 http://127.0.0.1:5177/ 。终端需保持运行，结束时按 Ctrl+C。服务仅监听本机地址，不需要 Spring Boot、MySQL 或安装新依赖。如果端口已占用，可先访问页面确认是否已有样稿服务，避免重复启动。

顶部依次切换「首页」「文章详情」「写作后台」「组件规范」。右上角「手机」将内容区域缩为 390px；也可以直接缩小浏览器窗口查看响应式效果。

## 本轮交付

| 页面 | 本轮设计内容 | 可操作的示例 |
| --- | --- | --- |
| 首页 | 个人首屏、原创主视觉、置顶精选、图文卡片、作者卡、分类入口与页脚 | 栏目切换、分类与关键词筛选、搜索弹窗、打开文章、空结果清空 |

设计沿用暗色技术方向。站名「萤火手记」、首页介绍和宣传语为提案；昵称 firefly1v、GitHub 项目链接沿用现有资料。头像采用原创字母 f 标识。主视觉、封面、图标与文章流程图均由本样稿的内联 SVG 绘制，没有引用参考项目的图片或下载外部字体。

参数以 `styles.css` 为准。1100、850、600px 使用内容容器断点，手机预览与真实窄窗口共享同一套布局规则。顶部样稿工具栏另有 640px 窗口断点。

宽屏首页以首屏主视觉、内容网格和作者侧栏组成；手机缩短介绍区、隐藏大幅插画、折叠筛选并转为单列。文章手机端保留正文空间，代码块自身可横向滚动。后台窄屏将侧栏改为顶部入口，文章设置位于编辑区之后。

按钮与链接有焦点样式；弹窗使用原生 dialog，目录使用 details；状态反馈使用 aria-live。支持减少动态效果偏好。当前没有完成全部键盘路径、读屏与颜色对比度的专项验收，正式实现时仍需检查。

## 演示范围

- 首页为六篇固定示例，统计与阅读时长均为样例值。分页只展示一页，归档、资源和关于为简化弹窗预览。
- 保存、发布与撤回只改变当前页面内存中的编辑草稿；刷新即重置，不调用业务 API，不写本地存储或数据库。发布不会把草稿加入首页固定示例。
- 文章管理展示当前编辑记录与六篇样例。载入其他样例会替换当前编辑草稿；尚未实现生产所需的未保存离开确认、回收站和持久化。
- Markdown 预览仅演示标题、加粗、列表、引用与围栏代码；正式业务仍需使用现有渲染方案并验证安全与兼容性。
- 地址中的 hash 用于样稿切换，不代表完整路由；文章没有独立可分享地址，浏览器历史恢复不在本轮验收范围。
- 加载、错误和404为组件样式示意，未模拟真实网络错误。样稿无需管理员登录。
