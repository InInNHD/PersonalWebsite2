# v0.4.0 — 栏目、分类与标签组合筛选

这是本地开发阶段的预发布版本，尚未部署到云服务器。

## 本次更新

- 文章列表支持栏目、分类、标签任意组合筛选。
- 清空标签后仍保留栏目和分类条件。
- 多标签文章在结果中只出现一次，同时展示完整标签。
- 未发布文章继续对访客不可见；非法标签编号返回参数错误。
- 快速切换筛选条件时，过期请求不能覆盖当前列表、错误或加载状态。
- 同步 README 和项目进度，并补充自动化测试和页面验收记录。

## 安装与升级

- 新安装：按 README 执行 database/000-init-article.sql 至 004-article-tag.sql，再配置 DB_URL、DB_USERNAME、DB_PASSWORD、ADMIN_PASSWORD。
- 从 v0.3.0 升级：没有新增数据库迁移，更新代码并重启前后端即可；不要重复执行已经应用的 SQL。
- 从更早版本升级：按照 README 补齐尚未应用的迁移。
- Release 提供源码下载，仍需自行准备 Java 17、Node.js 和 MySQL。真实密码、依赖目录及构建产物不包含在源码中。
