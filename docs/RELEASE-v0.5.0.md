# v0.5.0 — 文章搜索与分页

本地开发阶段的预发布版本，尚未部署到云服务器。

## 本次更新

- 公开文章列表支持标题及摘要子串搜索，空白关键词相当于不搜索。
- 搜索与栏目、分类、标签同时生效，总数和本页内容使用相同筛选条件。
- 默认每页 10 篇，支持上一页、下一页，总数及页码展示；历史文章不再受最新 20 篇限制。
- 搜索提交、清空搜索或筛选条件变化回到第一页，翻页保留已提交的搜索词。
- 未提交的输入框文字不影响翻页；清空搜索保留栏目、分类、标签。
- 过期请求不能覆盖当前列表、总数、页码、错误或加载状态。
- 草稿继续不可见；多标签文章不重复，卡片及详情保留完整标签。
- 补齐接口格式适配、分页边界、特殊字符和前端行为回归测试。

## 接口兼容性

**公开文章列表的返回格式发生变化，升级时必须同步前后端。**

`GET /api/articles` 从数组改为分页对象，字段为 `items`、`total`、`page`、`size`、`totalPages`。默认 `page=1`、`size=10`，`size` 允许 1～50；页码范围为 1～1000000。

新增可选 `keyword` 参数，去掉两端空白后最多 100 个字符，只搜索标题与摘要。`%`、`_`、`!` 作为普通字符处理，不作为通配符。

超过最后一页时返回最后一页，并在响应中给出实际 `page`。无结果时 `items=[]`、`total=0`、`page=1`、`totalPages=0`。

`GET /api/articles/{id}` 与管理员文章接口保持原来的返回格式。

## 安装与升级

- 新安装按 README 执行 `database/000-init-article.sql` 至 `004-article-tag.sql`，配置数据库连接和管理员密码。
- 从 v0.4.0 升级无需新增数据库迁移，更新前后端代码并重启；不要重复执行已应用的 SQL。
- 自行使用文章列表 API 的调用方须改为从 `items` 读取文章，并使用分页元数据。
- 运行仍需 Java 17、Node.js、MySQL 及本地连接配置；不提交真实密码、依赖目录或构建产物。

## 当前范围

搜索首版只覆盖标题和摘要。子串搜索及页码分页适用于当前个人网站规模；跨请求有内容发布或修改时，页码及结果可能变化。

文章归档、关于页、展示完善、全站移动端验收、备份恢复及云部署留待后续阶段。390 像素文章页面检查不代表全站移动端验收已完成。
