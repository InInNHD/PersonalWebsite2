## 打开方式

在项目根目录运行，无需MySQL、Spring Boot或安装依赖：

```powershell
cd E:\PersonalWebsite2
node docs/design-v3/preview.mjs
```

打开 [第三版首页](http://127.0.0.1:5188/)。服务仅监听本机127.0.0.1:5188，只提供六个样稿运行文件，不提供其他文档、配置或私人清单。端口占用时先确认是否已有本轮服务，避免重复启动。前台运行可用Ctrl+C结束。

页面直达：[首页](http://127.0.0.1:5188/#/) · [文章库](http://127.0.0.1:5188/#/articles) · [项目](http://127.0.0.1:5188/#/projects) · [阅读](http://127.0.0.1:5188/#/article/request)。直接双击HTML不支持模块和快照加载，请通过服务打开。

## 设计与交互

保留暗色、字母f和淡绿色强调，首页用内容图示替代大幅装饰主视觉。桌面正文最大1240px外框，文章正文约760px；移动端优先保留标题、摘要和操作。正文有16/19px两档字号，专注模式保留退出入口。封面和图示是本轮原创SVG，不依赖外部图床或字体。

| 页面 | 交互 |
| --- | --- |
| 首页 | 精选阅读、专题3篇顺序入口、文章/项目导航、同数据第二版结构对照 |
| 文章库 | 标题/摘要/正文搜索、栏目与标签组合、专题、卡片/紧凑模式、两页演示内容、空结果重置 |
| 项目 | 7个公开仓库、fork标识、项目说明弹窗、仓库外链、项目＋事件类型筛选及更新分页 |
| 阅读 | 目录定位与高亮、字号、专注/退出、复制代码、复制干净样稿链接、专题下一篇、返回来源列表 |
| 通用 | 手机菜单、全局搜索及Ctrl/Cmd+K、Esc关闭弹窗与焦点恢复、键盘跳到正文 |

“关于、归档、资源”在本轮仅为说明弹窗；正式接入时保留第二版完整页面。日记使用演示栏目筛选。项目资料来自2026-10-23既有快照，最新事件尚未包含随后发布的第二版RC；页面明确提示不是实时同步。

详细的真实内容盘点、候选采用顺序、8篇演示清单与项目说明边界见[内容策划](CONTENT-PLAN.md)。未公开草稿正文没有复制到本目录。

## 推荐评审顺序

1. 看首页能否直接找到代表文章、主题和项目；点顶部“对照第二版结构”比较，再返回第三版。
2. 文章库搜索“事务”（仅正文命中），选择Vue标签应出现空结果；重置后翻第二页，观察长标题和默认封面。
3. 切换紧凑模式，打开文章，再从正文返回，检查条件/页码/列表模式仍保持。
4. 项目页展开案例，核对描述是否符合本人实际工作；筛选项目与推送/Release/历史提交。
5. 阅读页试目录、字号、专注模式和复制；窄屏展开菜单和目录。

## 范围与下一步

- 本轮样稿是原生HTML/CSS/JavaScript，便于独立评审；业务实现继续使用Vue3/Java17/MySQL。
- 搜索和分页作用于8篇内存样例，项目筛选作用于公开静态快照；不代表第三版后端接口或真实全文检索已经完成。
- 样稿使用hash路由。正文复制链接只用于本机预览，不提供正式canonical、OG、RSS、SEO或跨设备分享服务。
- 列表位置与阅读偏好只在当前页面会话保留。刷新会重置偏好；查询参数仍可重现筛选。
- 真机触摸/软键盘、其他浏览器、正式性能与完整无障碍审计本轮未覆盖。四档视口不能等同真机通过。
- 数据库只读盘点、业务源码无变动；未重跑业务测试、迁移、发布文章、提交、推送或Release。
