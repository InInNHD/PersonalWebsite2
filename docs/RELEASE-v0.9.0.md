# v0.9.0 — 内容导航、公开日记与GitHub项目展示

**本地开发阶段的预发布版本。** 基于已发布的v0.8.0（bee1ca9），本轮包含第二版第四轮4A、4B、4C，仍用于本地迭代。

## 更新内容

- 新增内容地图和分类/标签落地页，按公开文章统计数量，支持分页及正文入口。
- 将归档升级为跨年月时间线，新增独立公开日记页；手机可用原生月份选择。
- 主题、归档、日记的筛选和页码写入URL；正文及前后篇保留来源，返回恢复列表位置。
- 完善关于页和共享头像，展示InInNHD全部公开项目；未提供的个人资料隐藏。
- 增加区分推送、Release、历史提交的日期更新链，支持项目/类型筛选、分页及可核对来源。
- 提供本地Node同步命令，完整成功后替换公开快照；失败保留旧文件，访客浏览不依赖GitHub或Java服务。

## 接口与升级

- 新增公开`GET /api/topics`，仅统计公开文章使用的分类和标签。
- `GET /api/articles/archive`新增可选`type`，支持公开日记月份目录；不带参数仍为全站公开归档。
- 从v0.8.0升级没有新增数据库迁移或依赖；更新前后端并重新构建，已执行005的数据库不要重复迁移。
- 新安装仍按README执行000～005并准备Java17、Node和MySQL。
- 根目录执行`node frontend/scripts/sync-github.mjs`，生成并随源码提交`frontend/public/github-profile.json`，随后构建前端。
- 推送/发布后重新同步。无法恢复未保存且已超出公开活动窗口的历史Push；历史提交日期不等同于推送日期。token只允许用于本机同步进程，不写入快照或前端配置。
