# 第三版第三轮验收：正文搜索与阅读体验

日期：2026-10-24。基线：已发布的 `11c7b24` / `v3.0.0-alpha.1`。本轮改动尚未提交或发布，构建版本暂沿用alpha.1；不是第三版整站正式验收。

## 完成范围

- 搜索扩展到Markdown正文，标题、摘要、正文依次优先，同级发布时间与编号倒序；保留原组合筛选和分页。
- 当前页返回有界片段与命中字段，Vue文本节点安全高亮，旧响应不会覆盖当前文章或片段。
- 标准/大字号、浏览器字号记忆、专注阅读、Escape退出、干净分享链接与复制失败后的手动复制入口。
- 切换布局保留当前段落位置；目录定位与当前章节高亮适应窄屏工具条换行；长代码块内部横向滚动。

使用规则和更新方法见[第33节](33-v3-search-reading.md)。无需新增SQL、依赖或后台配置。

后端新增6项场景覆盖中文、Emoji、C++、百分号/下划线/感叹号、HTML文本、标题优先稳定分页、分类/标签/月/栏目组合以及草稿/回收/撤回隔离。两项旧测试随搜索规则更新：原“正文不命中”改为正文命中，原纯时间排序改为标题优先；原分页去重、输入校验、符号字面匹配和注入防护断言保留。

本机数据库服务实测为 **MySQL 5.7.39-log**，并非客户端安装目录名称所指的版本。片段查询改用派生表，实际测试通过，不需要WITH/CTE或数据库升级。

浏览器自动化语义点击会先滚动吸顶按钮，曾造成位置变化的假象；改用截图确认后的实际按钮位置点击，字号切换和专注切换的章节位置偏差均不足1px。正文关闭浏览器自动滚动锚定，由段落位置补偿处理布局切换。另修正窄屏工具条换行后的当前章节判断，并补入现有回归测试。

## 数据与环境

验收使用独立数据库、仅有该库增删改查权限的临时账号，以及绑定127.0.0.1的8090/5190服务。15篇演示记录含13篇公开、1篇草稿和1篇回收文章；发布/撤回仅操作演示文章。个人库八张表在验收前后通过完整数据指纹比对，未变。

临时进程、数据库、账号和凭据已清理。截图、日志和结果存放在忽略目录 `artifacts/v3-round3/`；不随源码提交。未更改个人介绍、真实文章、精选/专题配置或现有服务。

## 限制与下一步

- 15篇样例下首次正文HTTP搜索约117.6ms，仅为本机小样本观察，不代表大数据量或线上性能。LOCATE仍扫描候选文章；大规模全文索引尚未引入。
- 实体手机触摸、软键盘及线上弱网未验证；四档浏览器宽度不能替代真机。
- 本轮复制的是干净文章地址；服务端分享HTML、OG、RSS与sitemap仍留第五轮。
- 已达到下一次第三版Alpha阶段预发布节点，发布需单独进行版本、提交与附件核对。本轮未执行Git提交、推送、标签或Release。
- 下一轮为第四轮可靠写作：先完成版本冲突检测和编辑稿/公开版分离，再推进修订恢复、自动保存与后台公开资料维护。
