# v0.11.0 — 资源分组与本地图片管理

状态：2026-10-22，第六轮资源与图片管理已实现并验收，经用户授权整理为v0.11.0阶段性预发布，基于v0.10.0（6a714fd）。版本标签绑定本轮业务、007迁移、备份工具、测试和文档的提交，尚未部署到云服务器。

## 更新

- 公开资源按用途分组，支持组内搜索、本站SVG图标、推荐理由与外链提示；后台维护分组和排序。
- 本地PNG/JPEG上传，真实内容、MIME、体积及像素校验，重新编码、随机文件名和受控存储目录。
- 编辑器图片库可选封面和插入Markdown正文，草稿使用受保护预览；媒体随显式文章关联公开，撤回/回收后按关联状态重新检查。
- 离线备份包含数据库、源码配置和媒体，提供只恢复到全新专用库/目录的命令及SHA256校验。

## 升级

从v0.10.0升级，先备份后执行一次 `database/007-resources-media.sql`；新安装执行000～007。本工作区个人库已执行007，不要重复执行。原五表数据逐字段一致，旧资源默认未分组。

同步更新并重启前后端。本站图片全部通过 `/api` 同源代理，不能直接公开媒体磁盘目录。`app.media.directory` 相对Java工作目录，建议明确绝对路径并在备份时使用同一路径；配置示例支持 `MEDIA_DIRECTORY`。

文章保存请求新增可选 `bodyMediaUrls` 显式授权正文媒体，当前前端按实际Markdown目标自动生成。资源接口保留旧字段并增加分组/图标/推荐说明。没有新增应用依赖；备份命令需要Python 3.12+（Windows）和MySQL客户端。
