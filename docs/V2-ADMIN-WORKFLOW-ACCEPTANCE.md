## 浏览器与HTTP流程

- 未登录直达分类标签页，转到带合法next的登录页；错误密码有页面反馈，正确密码回原页面。
- 站内新增分类、标签并改名；编辑器选择分类和标签后保存、恢复均保留。
- 新建公开精选日记，填写Markdown及原始script文字；预览不会执行原始HTML。首次保存进入正式编号地址，再保存不会重复新建。
- 注入发布503，显示“已保存，但发布未完成”；注入写入401，原页重新验证且输入保留；解除故障后继续发布成功。
- 日记发布前明确提示公开范围；发布→撤回→再发布→回收→恢复后为草稿，正文、分类和标签保留。
- 真实HTTP分别验证回收及恢复草稿：详情与前后篇404，公开列表、归档、日记、主题及统计均排除该记录。
- 标题未保存时导航确认取消及Escape均保留输入；编辑/预览/分屏正常。1440px双列，其余验收宽度单列。
- 标题关键词、草稿、笔记、分类组合筛选得到12条匹配；第二页连续回收最后两条后自动纠正到第一页，网址保留其余筛选。
- 手机资源输入FTP地址，后端拒绝并显示输入校验提示；改为HTTPS后隐藏保存成功。真实退出成功。
- 浏览器验收最终未记录控制台错误；个人首页仍显示原有3篇公开文章。
