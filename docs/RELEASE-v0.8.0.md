# v0.8.0 — 文章阅读体验与连续阅读

本地开发阶段的预发布版本，基于 v0.7.0（beef2dc）。本轮包含第三轮 3A 阅读基础、3B 代码与图片、3C 前后篇导航，整个第二版仍继续迭代，尚未部署到云服务器。

## 本次更新

- 更新文章头部、中文元信息和正文布局，显示约计阅读时长。
- 为 h2/h3 生成唯一章节锚点和目录，支持章节直达、当前章节高亮、阅读进度与回到顶部。
- 正文加载并渲染后再定位章节或恢复浏览器位置，图片加载后重算阅读进度。
- 按需加载九种语言的代码高亮，显示语言标签；未知语言和高亮异常回退为转义后的纯文本。
- 复制对应代码块的原文，保留缩进与结尾换行，提供成功/失败反馈，并丢弃离页或换文后的异步结果。
- 普通正文图片支持点击或键盘打开大图，通过关闭按钮、Escape 或背景关闭，恢复焦点和页面滚动；坏图片给出提示。
- 新增仅针对公开文章的前后篇入口，支持跨栏目连续阅读，保留合法的原列表筛选和返回位置。
- 导航请求独立处理加载、错误和重试，失败时正文仍可阅读；首尾没有相邻文章时显示边界文字。
- 新增第三轮手敲指南、实际源码回归测试及整轮验收记录。

原始 Markdown HTML 继续禁用，代码、语言标签和章节名称保持转义，危险链接及图片协议不生成可执行入口。图片查看使用原生 dialog；代码复制使用浏览器剪贴板 API，不可用或被拒绝时提示手动复制。

## 接口与兼容性

新增 `GET /api/articles/{id}/neighbors`，返回 `previous`（较早）和 `next`（较新），无相邻项时为 null；链接项只包含编号、标题和首次发布时间。

当前及相邻文章都必须为已发布且发布时间非空的记录。导航按 `published_at` 与 `id` 稳定排序，不受置顶、更新时间或列表筛选影响。当前文章不存在、为草稿或没有发布时间时返回 404，不泄露其邻居。

现有列表、详情和管理员接口保持兼容。本轮新增固定版本 `highlight.js 11.11.1`，依赖锁文件已同步，只加载九种常用语言。

## 安装与升级

- 从 v0.7.0 升级：没有新增数据库迁移，更新前后端、在 frontend 运行 `npm ci` 并重新构建/启动。
- 从 v0.6.0 或更早版本升级：先备份并补齐尚未执行的迁移，尤其是 `005-article-presentation.sql`；已完成 005 的数据库不要重复执行。
- 新安装按 README 执行 000～005，准备 Java 17、Node.js、MySQL 及四项本地环境配置。
- GitHub Release 提供版本标签对应的源码下载，不包含个人数据库、备份、真实密码、依赖目录或构建产物。

## 当前边界与下一轮

前后篇是全站公开文章的时间顺序，不是当前筛选结果中的相邻文章。列表精确位置仍只保存在当前页面会话最近 20 组查询中，刷新后不保证恢复原滚动位置。

图片查看不是图片上传服务，剪贴板功能依赖浏览器支持与权限。本次响应式检查使用 Chromium 的 320/390/768/1440px 视口，不代表全部真实设备及浏览器兼容性均已覆盖。

下一轮是内容导航与个人展示；第三轮通过不代表第二版所有轮次已经完成，云部署继续后置。
