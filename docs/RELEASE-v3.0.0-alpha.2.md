# v3.0.0-alpha.2 — 正文搜索与阅读体验

日期：2026-10-24。基于v3.0.0-alpha.1（11c7b24），本轮为第三版第三轮阶段预发布。前端、锁文件及Maven版本统一为3.0.0-alpha.2；第三版RC/正式版及云部署尚未完成。

## 更新内容

- 搜索从标题、摘要扩展到原始Markdown正文，支持原有栏目、分类、标签、月份与分页组合。
- 有关键词时标题命中优先，其次摘要、正文；同级按发布时间和编号倒序。无关键词时沿用原置顶/归档排序。
- 当前页返回有界命中片段及来源字段，通过Vue文本节点高亮，HTML文字不会变成可执行元素，过期结果不能覆盖当前页面。
- 提供16px标准字号与19px大字号，按浏览器记忆；存储不可用时仍允许本次切换。
- 专注模式、Escape退出及焦点恢复；图片弹窗优先处理Escape。布局切换保持当前段落位置，窄屏目录适应工具条换行。
- 复制干净文章链接，移除from、查询条件及章节锚点；复制失败提供手动复制入口。

## 搜索规则与接口

输入按普通子串处理，不拆词，不接受正则或布尔语法；Markdown代码、链接和标记也可能命中。LOCATE匹配遵循字段排序规则，未引入全文索引。公开条件同时约束计数、分页及片段，草稿、回收和撤回内容不公开。

列表保留原分页字段，新增matches，按当前页文章编号返回优先命中字段的片段；无关键词或无结果时为空对象。每篇仅展示优先字段的首个命中，前后各最多60个Unicode字符，不向列表返回完整正文。详情见[使用指南](33-v3-search-reading.md)。

## 升级及附件

无新增SQL、依赖或后台配置。已完成007的安装不要重复迁移；更新、重新构建并重启前后端。正文搜索与片段要求匹配版本的后端，不能只更新前端。新安装及更早版本按README补齐缺失迁移和环境配置。

附件提供personalwebsite-3.0.0-alpha.2-source.zip、personalwebsite-3.0.0-alpha.2-frontend.zip、personalwebsite-3.0.0-alpha.2.jar及SHA256SUMS.txt。源码从最终标签提交生成，另两个产物来自本次公开配置构建，发布时核对服务器SHA-256。

静态前端仍需HTTP服务、SPA路由回退和同源/api代理；数据库、配置和匹配媒体需自行准备。个人草稿保持未公开，精选/专题配置未调整，GitHub快照保留现有范围，本次发布将在下次手动同步后纳入。

## 限制与下一轮

实体手机触摸、软键盘及线上弱网未验证。15篇样例下的本机搜索耗时不能代表线上性能，LOCATE仍扫描候选文章，大数据量索引优化另行评估。

本轮分享功能仅复制干净地址，服务端分享HTML、OG、RSS和sitemap仍留后续。下一轮进入可靠写作，先做版本冲突检测与编辑稿/公开版分离，再推进修订恢复和自动保存；云部署继续后置。
