## 4. 个人内容只读核对

使用同一实际后端产物，以临时进程环境变量连接`personal_website`，只发送公开GET请求：

- 3篇公开文章的前后篇均与数据库中的`published_at,id`排序一致，响应仅有链接字段。
- 1篇草稿的导航和正文均返回404。
- 浏览器从“第一篇笔记”进入下一篇“后台发布测试”，再返回`/?type=NOTE&keyword=第一`，原筛选恢复且只显示1篇结果。
- 本轮开始、只读核对和最终清理时，个人库五表校验值一致，写入数为0。
