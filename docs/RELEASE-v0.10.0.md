# v0.10.0 — 独立后台与完整写作流程

状态：2026-10-21，第五轮写作后台重构与统一验收通过，经用户授权整理为本地开发阶段的v0.10.0预发布版本，基于v0.9.0（928a010）。版本标签绑定本轮业务、006迁移、测试和文档的发布提交。

## 更新内容

- 独立管理员登录、后台布局、文章管理、新建/编号编辑、分类标签和资源入口。
- 服务端搜索、状态/栏目/分类组合筛选、分页与网址条件保留。
- Markdown工具栏、编辑/预览/分屏，保存状态、封面置顶、分类标签维护。
- 首次保存同步正式编号网址，后续保存不重复创建；发布前先保存，部分失败有明确反馈。
- 撤回公开、文章软回收及恢复为草稿；所有公开读取与计数统一隔离回收内容。
- 站内确认与未保存保护，原页重新验证密码并保留输入，真实CSRF退出流程。

## 升级注意

1. 先备份数据库。从v0.9.0升级，在正确目标库执行一次 `database/006-article-recycle.sql`；新安装执行000～006。已在本机执行006的库不要重复执行。
2. 同步更新前后端、重新构建并重启。`GET /api/admin/articles` 由数组改成分页对象 `items/total/page/size/totalPages`，旧管理前端不能直接兼容；后台详情新增 `deletedAt`。公开详情格式不变。
3. 管理认证仅内存保存，刷新重新登录；实际配置和管理员密码沿用本机配置，不随源码发布。
4. 回收不是物理删除，恢复不会自动公开。首次发布时间保留，重新发布仍归入原发布时间月份。

本轮没有新增依赖。运行环境仍为Java17、MySQL与项目现有Node/Vite环境。Release为源码版本，运行仍需自行准备本地配置和数据库。
