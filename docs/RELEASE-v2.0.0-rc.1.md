# v2.0.0-rc.1 — 个人网站第二版候选预发布

日期：2026-10-23。基于v0.12.0（8644c70），前端、锁文件及Maven构建版本统一为2.0.0-rc.1。这是候选预发布，不是正式v2.0.0或云部署；原拟v0.13.0的恢复加固并入本次RC，不另建该版本标签。

## 第二版功能与本次收尾

- 首页图文展示、公开统计、分类标签、搜索分页、时间线归档、公开日记及GitHub项目更新链。
- Markdown目录、代码高亮/复制、图片查看、阅读进度、前后篇和来源列表位置恢复。
- 独立后台、保存/发布/撤回/回收/恢复、未保存保护与认证失败保留输入。
- 资源分组、本地图片校验与公开隔离，数据库/配置/媒体备份恢复。
- 统一加载/空/错误/404、动态元信息和键盘交互。
- 加固恢复失败回滚，保护已有数据库，清理本次失败创建的库或媒体文件。
- 应用经用户确认的公开介绍；GitHub快照更新为7个公开项目、172条记录，fork历史提交仅保留本人的记录。

## 验证与已知限制

- 本次复检实际前端75项、恢复工具5项和前端生产构建均通过。
- 21个Java源码/测试与候选记录逐一SHA-256一致；候选JAR重新打包且配置仅为公开环境变量模板。本次沿用2026-10-22真实MySQL32项、新装/升级/数据库与媒体恢复及64组屏宽检查，不声称再次执行数据库测试。
- 用户已认可暗色技术风格；实体手机触摸、软键盘和写作表单按用户要求暂缓，状态为未验证。
- 未完成Safari/Firefox、并发压测、弱网评分或搜索引擎抓取验证；动态元信息不等于服务端渲染。
- 数据库中3篇新文章仍是草稿，未公开；原测试文章未擅自撤回或删除。草稿全文文档已排除出Git及Release附件，源码包不包含个人数据库内容。

## 升级与运行

从v0.11.0或v0.12.0升级无新增SQL，已完成007的个人库不要重复迁移。更早版本按README先备份并补齐缺失迁移，新安装执行000～007。

运行需要Java17、MySQL和相应Node环境。JAR使用DB_URL、DB_USERNAME、DB_PASSWORD、ADMIN_PASSWORD和可选MEDIA_DIRECTORY环境配置。数据库和匹配的媒体文件需自行保管和恢复，不能由源码包替代。

前端静态包需要HTTP服务、SPA路由回退与同源/api代理；不能双击index.html运行，也不能把API错误回退成HTML。开发服务器不作为线上服务，云部署另行规划。
