# 第三版第二轮验收

日期：2026-10-24。范围：工作区业务源码，基于 `v2.0.0-rc.1`；未提交、未推送、未创建Release，构建版本未改动。

## 已实现

- 新首页与 `/articles` 文章库分离；旧首页筛选参数及锚点迁移，详情地址和返回来源兼容。
- 首页精选、学习专题及专题内上一节/下一节。公开状态每次查询重新判断；不足两篇的专题隐藏并返回404。
- 独立项目页：本站案例、关联实践笔记、全部7个公开仓库及既有172条三类记录快照。未借本轮修改或扩大同步范围。
- 文章库卡片/紧凑布局切换，会话内正文返回时保留密度。
- 配置校验、请求过期保护、独立失败重试、空状态及响应式布局。

配置入口与操作步骤见[内容组织指南](32-v3-content-organization.md)。`presentation.json` 默认精选、专题、项目关联均为空：没有替用户把测试文章列为精选，也没有发布私人草稿。
